# #261 Historical Validation — Failure and Miss Ledger

Preserve errors. Do not edit them away when the methodology changes later.

## Error types

Architecture wrong; bottleneck migration; capture failure; substitution/integration; materiality failure; valuation; dilution/capital intensity; timing; false negative; data limitation.

A v2 implication is a research observation, not permission to modify the frozen v1 specification before holdout completion.

# Fusion Enabling Infrastructure — Governance Note

All fusion research follows normal repository governance:

- canonical documents, no versioned duplicates;
- FACT / INTERPRETATION / HYPOTHESIS / OPEN QUESTION separation;
- recoverable sources;
- GitHub issues as authoritative execution state;
- branch + PR audit trail for substantive updates;
- no merge while required checks are pending/failing;
- portfolio conclusions change only through explicit current evidence.

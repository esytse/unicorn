# Prefabricated AI data-center power distribution certification discovery

Backlog: #288, parent #261.

## Trigger
On 23 Sep 2026 UL Solutions launched a certification pathway for prefabricated data-center power distribution systems and awarded the first certification to Schneider Electric.

## Architecture change
AI data centers are shifting from site-built electrical infrastructure toward factory-integrated modular power systems. Certification can become a qualification gate for repeatable hyperscale deployment.

Value chain: grid connection -> switchgear -> transformer -> UPS/storage -> busway/PDU -> controls/protection -> factory integration -> certification -> commissioning/service.

## Capture
Schneider is the first architecture validator but is already a large canonical comparator. Existing nVent, Vertiv, Eaton and transformer names may benefit from modular deployment, but the current evidence does not establish a new system-level qualification moat or company-material engine for a smaller listed supplier.

Certification could create switching friction and repeatable procurement, but it could also consolidate value into large integrated vendors while standardizing components.

## Result
Governed negative promotion result. No new company is promoted.

Reopen only if a smaller listed supplier receives system certification, wins a named hyperscaler modular-power award, discloses certification-driven backlog/capacity reservation, or reaches 5-15% revenue from the new architecture.

No Gate-E action changed.

# AI memory-capacity / CXL controller discovery — 25 September 2026

**Method:** agentic/inference memory pressure → capacity/pooling architecture → controller qualification → company materiality.

## World change

AI inference is becoming memory-capacity intensive, especially long-context/KV-cache workloads. The response is moving beyond simply buying more DRAM:
**memory expansion → pooling → tiering → fabric-attached memory → reuse of installed memory.**

Fresh 2026 state changes:
- Astera Labs launched new Leo controllers for fabric-attached GPU memory and CXL 3.2 expansion, citing new design wins across AI labs/hyperscalers/neoclouds.
- Montage Technology announced industry-first trial production of a CXL 3.2 MXC controller.
- Current reporting says Montage's CXL 3.2 MXC has been introduced into Samsung and SK hynix next-generation CXL products, with 2027 seen as a commercialization window.
- Kioxia is preparing CXL module samples; Samsung/SK hynix are moving toward CXL 3.2 product commercialization.
- Marvell demonstrated end-to-end CXL memory infrastructure with Intel.

The scarce complement is increasingly **memory-controller / fabric intelligence**, not just DRAM bits.

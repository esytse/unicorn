# AI Memory — Working Thesis

**Status:** Working thesis  
**Confidence:** Low  
**Last substantive update:** 2026-09-06

## Current thesis

**HYPOTHESIS:** AI infrastructure may be shifting from a predominantly compute-constrained race toward a broader system bottleneck in memory capacity, bandwidth, latency and data movement.

**HYPOTHESIS:** If that is correct, attractive value may accrue not only to memory manufacturers but also to companies that own difficult-to-substitute dependencies around memory interfaces, controllers, packaging, testing, interconnects and emerging memory architectures.

This is a research hypothesis, not an established conclusion.

## Current research candidates

- Montage Technology — investigate memory-interface and related infrastructure exposure
- Weebit Nano — investigate emerging-memory commercialisation, defensibility and adoption
- Micron — established memory benchmark and direct exposure

Candidate inclusion means "worth researching", not "investment recommendation".

## What would strengthen the thesis?

- Evidence that memory or data movement increasingly constrains AI-system performance or economics
- Durable pricing power or dependency at specific layers of the memory value chain
- Strong adoption evidence for smaller enabling companies
- Evidence that enabling layers capture attractive margins or returns on capital

## What would weaken the thesis?

- Rapid commoditisation of key memory-enabling layers
- Architectural changes that bypass the identified bottlenecks
- Customer concentration or vertical integration eliminating supplier leverage
- Strong technical promise without credible commercial adoption
- Valuations that already fully price in the upside

## Open questions

1. Which bottlenecks are structural rather than cyclical?
2. Which suppliers are genuinely difficult to substitute?
3. Where is market power concentrated across the end-to-end value chain?
4. Which emerging companies have evidence of commercial inflection rather than only technical promise?
5. Which public companies offer asymmetric upside versus established large-cap exposure?

## Evidence status

The thesis above currently captures the direction of the research. It should not be promoted to higher confidence until sourced evidence is added and contradictory evidence is actively tested.
